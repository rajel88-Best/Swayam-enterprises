Site admin

Sign in with a GitHub access token. Nothing is stored in this website's code — GitHub does the checking.

  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate a token. Repository access: only this website's repo.
  3. Permissions → Repository permissions → Contents: Read and write
  4. Copy the token and paste it below.

Keep this token private. Anyone who has it can change the website. Never paste it into WhatsApp or share the screen while it's on. If it leaks, delete the token on GitHub and make a new one — nothing else needs changing.
