One-time setup

Run this once, on a laptop. It creates the login for the site admin. After that, nobody needs a token again.

1. Get a GitHub token

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token. Repository access: Only select repositories → this website's repo
  3. Permissions → Repository permissions → Contents: Read and write
  4. Set expiry as long as GitHub allows, then copy the token

2. Fill this in

At least 12 characters
Choose a long password. The encrypted file sits in a public repo, so a short or common password can be cracked offline. Use four unrelated words, or a password manager. Write it down somewhere safe — nobody can recover it.
